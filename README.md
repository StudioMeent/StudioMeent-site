# Studio Meent — website

A simple static website: plain HTML, CSS and JavaScript. No database, no CMS.

## How it's organised

```
website/
├── index.html        BASE — landing page (Works, News, About, Contact)
├── base/             BASE — style.css, app.js, back-button.js, images/
├── build.js          BASE — makes the project list for the Works grid
├── content.js        Site texts: news, about, contact, filter words
├── projects/         One folder per project — this is what grows
│   ├── _template/    Starting point for a new project (skipped by the build)
│   └── projects.js   Generated by build.js — don't edit
├── CLAUDE.md         Working rules for Claude
├── CHANGELOG.md      Log of every change
└── README.md         This file
```

The **base** stays the same. Adding a project never changes it.

## Adding a project

1. Copy `projects/_template` and rename the copy, e.g. `projects/my-project`
   (lowercase, hyphens, no spaces) — or drag in a finished project folder.
2. Fill in `info.json` and replace `thumbnail.jpg` (square, under ~400 KB).
3. Build the page in `index.html` — any design. Keep the back-button line in the `<head>`.
4. In the website folder, run: `node build.js`
   It checks every project and updates the Works grid. It tells you if something is missing.
5. Open `index.html` in a browser and check.
6. Add a line to `CHANGELOG.md`, then commit and push.

`node` is Node.js (free, nodejs.org). Once the site is hosted on Netlify or Cloudflare Pages, the build runs automatically on every push.

## Editing texts

- News, About, Contact, filter words: `content.js`
- A project's title, year, categories, place: that project's `info.json`, then `node build.js`
- A project's page: that project's own folder

## Previewing

Double-click `index.html`, or in VS Code use the "Live Server" extension (right-click `index.html` → Open with Live Server).
